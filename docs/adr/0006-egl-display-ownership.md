# ADR 0006: EGL backend renders headless and never terminates a display
Status: accepted (Phase 4). Supersedes the Phase 4 sketch that proposed a private, reference-counted display per instance.

**No `eglTerminate`, ever.** EGL returns the *same* `EGLDisplay` handle to everyone who asks for the same platform and native display, and `eglInitialize`/`eglTerminate` are not reference counted. A guest that terminates "its" display destroys the contexts of any other library using it (JavaFX/GTK, ANGLE, another GL toolkit). A private display per Tessera instance would need a private native connection (an X11 `Display*`, a `wl_display`), which is exactly the dependency on the host's windowing system this backend avoids. So displays are initialised and then left initialised; contexts and surfaces Tessera created are destroyed, and that is all. Cost: one initialised display per platform for the life of the process.

**Headless only.** Tessera never creates windows through EGL. A default drawable is a 1x1 pbuffer; `TESSERA_SURFACE_NONE` is a true surfaceless context (`EGL_KHR_surfaceless_context`). Consequences: no swap chain, so `TESSERA_FLAG_DOUBLE_BUFFER` and stereo are refused in strict mode and dropped (with a log line) in best-effort mode; `tesseraSwapBuffers` is a no-op; swap interval is `UNSUPPORTED`; windowed rendering on EGL is out of scope. Platforms tried in order: `EGL_MESA_platform_surfaceless`, `EGL_EXT_platform_device` (GPU chosen with `TESSERA_EGL_DEVICE`), then `eglGetDisplay(EGL_DEFAULT_DISPLAY)`; `TESSERA_EGL_PLATFORM` forces one.

**Per-thread state.** EGL's current context is per client API, and `eglBindAPI` decides what `eglGetCurrentContext` answers, so a guest must save and restore both, for both APIs. Every operation does, and make-current/release/destroy also put the thread's bound API back. Implementations differ (Mesa keeps a single current context per thread), so Tessera does not rely on cross-API independence; it only guarantees it restores what it saved. The thread's last-error code cannot be preserved.

**Selection.** On Linux the order is GLX, then EGL; a backend that cannot serve a request at all returns `UNSUPPORTED` and the next is tried, which is how a headless machine (no `DISPLAY`) ends up on EGL. `TESSERA_BACKEND=glx,egl` restricts and orders them.
