# ADR 0010: Interop through native handles, strict window-attach ownership, pooling of unused contexts only
Status: accepted (Phase 8).

**Hand out the native objects; do not wrap the interop APIs.** WGL_NV_DX_interop2, EGL dma-buf import/export, IOSurface and Vulkan memory objects are each a large, driver-specific surface that changes independently of OpenGL. Wrapping them would make Tessera a graphics-interop library with a permanent compatibility burden and no way to test most of it here. What a consumer lacks is *access to the objects*: the `HGLRC`/`HDC` to pass to `wglDXOpenDeviceNV`, the `EGLDisplay` for `eglCreateImage`, the `Display*`/`GLXContext`. `tesseraGetNativeHandles` provides them (borrowed, valid until the context is destroyed, never to be destroyed by the caller) and `tesseraGetProcAddress` already resolves the extension functions. `test_dxinterop` proves the combination is sufficient for a real zero-copy OpenGL -> Direct3D 11 handoff. Handles are `uint64` entries in a fixed array with a per-backend meaning documented in the header, so the struct is the same on every ABI and new backends do not change it.

**Window attach: borrow, adopt, never modify behind the owner's back.** A Windows window's pixel format can be set exactly once, so changing a foreign window is irreversible. The rules: (1) the window is borrowed and outlives its use (we never destroy/resize/show it; destroying the context releases only the DC we took); (2) an existing format is adopted and checked (strict mode fails with `NO_MATCHING_CONFIG` on mismatch, best-effort reports what the window really has); (3) a missing format is set only if the caller passes `TESSERA_ATTACH_ALLOW_PIXEL_FORMAT`, because only the caller knows the window is fresh; (4) a vanished window yields `PLATFORM` errors (an `IsWindow` check on WGL, a scoped X error handler on GLX) rather than a crash or Xlib's exit handler. On GLX the framebuffer configuration is derived from the window's visual, because GLX cannot change a window's visual; a visual can map to several configurations (single/double buffered), so the one agreeing with the requested buffering is preferred. The call is implemented only where the window handle is a plain integer we can validate (`HWND`, X11 `Window`); EGL/CGL/Wayland return `UNSUPPORTED` rather than guessing.

**Pool only contexts that were never used.** A reused context carries GL state, objects and driver-side caches from its previous user, which is exactly the cross-contamination this library exists to avoid, and there is no complete way to reset a context. A never-used context built from an identical request is indistinguishable from a freshly created one, so handing it out is safe by construction, and it removes the 25-30 ms creation cost from the caller's path. Requests that share (`shareWith`) never use the pool because the new context must be created with that parent. The pool is capped (64), keyed on every field that shapes the context, and emptied at terminate. The caller decides when to pay for warming (`tesseraPrewarmContexts` blocks; call it from a background thread): there is no hidden background thread.

**Device selection never falls back silently.** `TESSERA_EGL_DEVICE` (index, render node, PCI address) used to skip non-matching devices and fall through to the default display, i.e. a different GPU than the one named. An explicit choice that matches nothing now fails with a message naming the setting; a choice also implies the `device` platform instead of being ignored by `surfaceless`.
